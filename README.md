# Quadratic Stability Control

MATLAB code for controlling a mechanical lattice when its masses, spring stiffnesses and damping coefficients are uncertain. The controller is designed from local models sampled at different states and parameter values.

This repository accompanies **Robust Sampling-Based Control for Elastic Lattices with Parameter Uncertainty**, by Ali Jnadi, Sergei Savin and Yaroslav Kholodov.

<img src="assets/lattice.png" alt="Four masses connected to their neighbours and fixed boundaries by axial and diagonal spring-damper interactions" width="700">

*The benchmark has four movable masses. Each mass can receive horizontal and vertical forces.*

## Getting started

You need **MATLAB**, the **Symbolic Math** and **Control System** toolboxes, and **CVX 2.2** with SeDuMi and SDPT3. The recorded experiments used MATLAB R2019b.

After installing CVX and running `cvx_setup`, open MATLAB in the repository root and run a small example:

```matlab
run_all_experiments('quick')
```

To run all experiments:

```matlab
run_all_experiments('full')
```

Full runs can take considerable time. Settings are in `qsc_settings.m`; detailed commands for the individual studies are in [Experimental protocols](docs/PROTOCOLS.md).

## Results

In the five-design comparison, nominal LQR has lower position error at **5% uncertainty**. At **10% and 15%**, QSC has lower position error but requires more force.

<img src="assets/five_design_comparison.png" alt="Position error and force effort for QSC and nominal LQR at 5, 10 and 15 percent parameter uncertainty" width="700">

*Each blue point is one QSC design's average over 1,000 common uncertain cases. Orange lines show nominal LQR on the same cases.*

Summary tables and figures are in `data/reference/`. This small download omits the large per-trial CSVs and saved MATLAB arrays; those remain in the full archive and can also be regenerated by running the experiments. New outputs are written to `results/`.

See the [paper-to-file guide](docs/PAPER_RESULTS.md) to locate a particular result. The stability certificate covers the sampled linear models and their convex hull; behaviour across the wider nonlinear domain is evaluated numerically.
